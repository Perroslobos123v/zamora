## Orden de documentos
Cada semana usa la misma estructura:
```
unidades/unidad-X/semana-Y/
  index.html      página de la semana
  documentos/     PDF y Word
  scripts/        .sql y .sql.html
  infografias/    imágenes propias de la semana
```
El **Centro de documentos** (`documentos/index.html`) lista todo por unidad y semana; se enlaza desde el menú lateral.
