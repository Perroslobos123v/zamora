Introducción a los Sistemas Informáticos · Semanas 1 a 4.

LAS 4 SEMANAS

SEMANA 01Formulación del proyecto y selección de la arquitecturaDefinir el alcance de un proyecto analítico a partir de un caso empresarial real, eligiendo y sustentando el tipo de arquitectura de base de datos (centralizada, distribuida o en la nube) que mejor responde a las necesidades de almacenamiento del negocio.›SEMANA 02Despliegue y configuración de motores de datos (DBMS)Instalar y configurar el sistema gestor de base de datos elegido para el proyecto, comprobando la conectividad y dejando listos los recursos iniciales del servidor.›SEMANA 03Modelamiento físico y mecanismos de integraciónEstructurar e implementar los esquemas y las tablas maestras dentro del DBMS, configurando las restricciones necesarias para que el almacenamiento y la integración de datos masivos sean eficientes.›SEMANA 04Sustentación y validación de la infraestructura de datosSustentar el primer avance del proyecto mediante un informe técnico y una demostración en vivo, comprobando que el diseño de la arquitectura y la carga inicial de datos cumplen con los criterios de rendimiento e integración planteados. Cierra con el ingreso de notas al sistema.›

Investigación

Comparación teórica de las ventajas, limitaciones y costos de transferencia de datos entre arquitecturas centralizadas, distribuidas y en la nube (SaaS/PaaS) aplicadas a la analítica de negocios.

Responsabilidad Social Universitaria

Diagnóstico tecnológico de una organización local, identificando sus carencias en el manejo de datos para proponer, de forma colaborativa, una arquitectura de almacenamiento eco-eficiente y de bajo costo.
